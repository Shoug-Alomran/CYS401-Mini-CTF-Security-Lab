A Capture-the-Flag Lab for Hands-On Security Learning

Our group project for CYS401: Fundamentals of Cybersecurity at Prince Sultan University. We are building a Mini Capture-the-Flag Security Lab Platform — a working tool where users solve security challenges, capture flags, and learn from the explanation that follows each one.

Overview

What We’re Building

The project follows the course path: assess the threats and vulnerabilities the challenges are drawn from, study how existing CTF platforms solve the problem, implement the working platform, and close with recommendations for using hands-on labs in security education.
