The CIA Triad is a foundational information-security model used to guide security policies and protect information and systems.

01 — Confidentiality

Keeping Secrets Secret

Confidentiality ensures that sensitive information is accessible only to those authorized to have access. It protects the secrecy of data, objects, and resources and aims to prevent or minimize unauthorized access, ensuring privacy remains intact across all organizational levels.

  • Soft Tokens
  • Key Fobs
  • Air-gapped Systems
  • Disconnected Storage

Common Violations

  • Stealing password files
  • Port scanning
  • Shoulder surfing
  • Eavesdropping
  • Sniffing
  • Privilege escalation
  • Human errors
  • Intentional harm

Security Measures & Protection

  • Encryption
  • Access Control
  • User IDs & Passwords
  • Two-Factor Authentication
  • Biometrics
  • Security Tokens

02 — Integrity

Trust the Data

Integrity provides assurance that information remains reliable and accurate. It ensures that data has not been modified or corrupted by unauthorized parties or accidental technical failures throughout its entire lifecycle.

Threats to Integrity

  • ●Viruses & Malware
  • ●Logic bombs
  • ●Unauthorized access
  • ●Coding errors
  • ●System backdoors

Methods of Protection

  • ✓File permissions
  • ✓User access controls
  • ✓Version control
  • ✓Checksums / Hashing

03 — Availability

Available When It Matters

Authorized users should be able to access information and systems whenever they are needed. Availability ensures uptime and provides resilience against physical disasters and cyberattacks.

Availability Protection

Architectural safeguards to ensure continuous system operation and data access.

  • Geographically Isolated Backups

  • Firewalls
  • Proxy Servers
  • Web Application Firewalls
  • Redundant Power & Hardware

One System, Three Requirements

Effective security requires balancing all three principles. Over-prioritizing one at the expense of others can lead to a dysfunctional or vulnerable system.
